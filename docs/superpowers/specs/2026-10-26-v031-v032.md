# 0.3.1 / 0.3.2 已确认范围与执行设计

沿用用户已批准的版本安排及 2026-10-25 智能体工作台方案，本次直接实施并 push / release。

## 0.3.1

- 设置增加默认关闭的 Codex CLI 统一续聊历史开关。稳定共享分组使用已有 csmy，避免再次拆分现有第三方历史。
- 官方登录通过独立官方镜像配置进入相同分组，保留 auth.json 与请求目的地；第三方沿用既有 csmy 配置。其他第三方分组配置冲突时拒绝覆盖并提示先导入。
- 既有 openai 历史仅在用户主动勾选时迁移。同步 session_meta.model_provider 与 threads.model_provider；支持归档、CODEX_HOME、sqlite_home 和 CODEX_SQLITE_HOME。未知数据库结构、锁占用、损坏元数据或扫描超限时拒绝迁移。
- 操作前持久化逐项账本及原始文件、数据库备份。失败按账本回滚；重启发现未完成操作时阻止继续并提供恢复。还原仅变更仍符合账本的 provider 字段，保留新增消息与用户后改字段，不反向修改新会话。
- 修复网页正常而软件登录超时的客户端网络差异：启用 Reqwest 系统代理、系统根证书，区分连接超时和等待响应超时；不降低 TLS 校验，不自动重复登录 POST。

## 0.3.2

- 已接入项增加显式连接诊断：检查检测状态、当前配置、凭据、兼容桥，再按所选模型和原协议运行既有两轮工具验证。配置变化或 Key 删除时不向网络发送请求，提示重新导入。
- 诊断只读，不覆盖配置；明确显示可能消耗少量额度。报告只含状态、协议、耗时、可操作建议，屏蔽凭据，不输出会话或原始配置。
- 快捷操作：从已接入项直接带入该智能体更换模型/Key，查看该工具会话、打开配置目录；保留启动命令复制及条件还原。
- 简洁白色界面，诊断按需弹出，不添加首页大面板。

## 验证与发布

各版本分别完成 Rust / 前端交互回归、TypeScript、Clippy、格式和 Web 构建。迁移只使用临时目录与模拟记录，不修改开发机真实 Codex 历史。每版单独提交、push、tag、四平台签名 Release，重新下载公开文件验签并核对更新入口，再推进下一版。
