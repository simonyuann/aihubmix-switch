## 信息架构

主导航：API、已接入、会话。工具箱放 MCP、Skills、提示词、用量和连接管理等后续能力；未实现的功能不放可点击空壳。首页不罗列智能体品牌，只展示已接入项。添加时打开可搜索的智能体目录，推荐最近使用和检测到的工具；每项说明自动写入或手动接入，CLI 与桌面 App 的检测分开。一次只选择一个工具和一个模型，高级参数默认折叠。

## 第一阶段首批交付

- 增加可搜索智能体目录，优先可用工具；已有四种自动接入保留。
- 新增 Grok Build、Kimi Code、OpenClaw 原生配置适配，沿用真实模型验证、最小字段写入和条件还原。
- 其他工具先提供明确的接入说明和官方入口，标注手动接入；逐批升级为原生适配，不把仅有名称的目录当作自动支持。
- 会话页首批支持 Claude Code、Codex、Pi、Grok Build、Gemini CLI、OpenClaw 的文件记录。OpenCode 的数据库会话与其他复杂格式在其专用读取器完成后加入；界面会显示当前可读取来源。
- 会话读取只在用户打开页面或刷新时发生，限制文件大小、扫描数量、消息数；不上传记录、不执行会话里的命令，不修改原工具数据。未支持格式和读取失败给出来源级提示，避免被当作无会话。
- 继续会话先提供可复制的原工具命令与工作目录；避免 shell 注入，不自动执行不可信 cwd/路径。跨 agent 续接属于独立上下文转换功能，不伪装成原会话恢复。

## 验收

新适配器使用临时目录验证配置格式、其他字段/注释保留、重复导入原始基线、用户后改字段保留、写入失败回滚。会话使用真实结构的脱敏 fixture 验证搜索/正文/恢复命令、损坏行、活动尾行、路径越界与软链接拒绝、数量/大小限制。前端验证搜索选择、手动/自动模式、只展示已接入项及只读会话。上线前完成类型检查、Rust/前端回归、Clippy、界面检查与四平台构建。
