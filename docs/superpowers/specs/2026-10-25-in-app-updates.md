# v0.2.2 应用内更新

用户已批准 Tauri 官方 Updater + GitHub Releases 方案并要求加入。启动后台检查更新、设置页手动检查、下载进度、用户确认安装和重启。检查失败不影响 API 工作台与本地 Claude 兼容服务，安装前明确提醒兼容连接会短暂中断。用户 Key、会话、CLI 路径和配置备份保留。

更新管理由 Rust 独立模块负责，不持有 API 后端的全局锁。客户端仅接受固定 HTTPS 发布端点及专用更新密钥签名，禁止降级；私钥不进入仓库、日志或应用。使用 Tauri 生成的原始更新归档及其签名，不重新压缩已签名归档。CI 对所有平台包完成测试、校验后才发布 Release 和 latest.json。区分系统、CPU 架构、安装格式，不将安装包静默套到免安装程序。

Windows 安装版、macOS app、Linux AppImage 采用原生更新；Linux deb 按插件实际支持情况调用系统包管理器授权升级。未支持的安装格式提供明确的覆盖升级入口，不宣称已安装更新。初次使用现有 v0.2.1 的用户需先覆盖安装 v0.2.2，此后可在应用内更新。

验证覆盖版本比较、平台匹配、下载失败/错误签名不安装、成功下载后用户确认才安装、重复点击与并发操作、更新元数据生成、生产签名验证以及真实旧版本到新版本的隔离升级演练。正式发布前执行类型检查、前端测试、Rust 测试/Clippy、四平台构建与产物核对。
