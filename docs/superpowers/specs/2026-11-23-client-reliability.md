# AIHub 1.2.0 客户端验收补充

首页和工具页都提供「移除分组」。用户选择正在使用的分组时，在弹窗中选择同一工具的可用替代项。先通过已有配置切换流程激活替代项，成功后再删除原本机卡片及绑定。切换失败时保留原卡片。无可用替代项时提示先添加并配置分组。移除后允许重新添加；最后一个未使用的分组被移除后，刷新页面应保持为空。账号和工具之间的分组独立，云端 API Key 继续可用。

新版更新清单及新生成的安装包链接使用标准 HTTPS。网络诊断分别检查账号服务和模型 API，报告时间、版本、网络阶段、状态及可用的请求编号。诊断报告只显示预定义字段。正式发布前通过独立更新清单在 Windows 验收老用户原地升级、第一条流式回答以及中途断网表现。

代码提交到 GitHub 的 1.2.0 开发分支，客户更新清单的切换属于独立的发布操作。
