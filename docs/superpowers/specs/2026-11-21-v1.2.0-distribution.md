# AIHub 1.2.0 更新和插件安装

## 客户端更新

使用现有更新清单、签名公钥与下载站域名。1.2.0 普通更新页订阅更新器发送的真实字节数，显示百分比、已下载和总大小。服务端未提供总大小时仅显示已下载大小。下载结束后显示校验、安装状态。避免重复提交更新。1.1.18 升到 1.2.0 时仍使用旧版界面。

## 插件市场

打开或启用市场仅获取目录。用户在 AIHub 中点击安装后，按目录中固定的版本和内容哈希，从海外服务器下载选中的插件并校验，再调用本机 Codex 安装。网络或校验失败时保留原有插件及注册信息。已安装的插件可继续使用。1.1.18 所需的整包及索引继续提供。

## 发布条件

复用仓库的多平台签名构建。Windows 安装版、macOS 更新包和 Linux deb 由海外服务器直接提供。Windows 便携版和 Linux AppImage 沿用 NAS 回源。先将文件部署到版本专用路径，在公网验证来源、签名、可下载性及断点续传，再切换更新清单。保留 1.1.18 用于兼容和撤回更新提示。

使用同一份 Windows 安装包验收全新安装和 1.1.18 原地升级，检查启动、登录界面、用户配置和插件市场。验证单插件安装时只下载目标包、损坏包被拒绝，以及更新进度在总大小未知时的显示。发布与上述验收结果绑定。
