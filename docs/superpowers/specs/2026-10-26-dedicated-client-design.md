# 自有 API 专用客户端

用户已明确要求执行：移除添加供应商，默认且仅支持自有 API；登录成功才能进入界面；首页支持登录、邮箱验证注册和密码找回；左下角删除 MCP、Skills、提示词、授权中心，替换为余额、充值与申请 API。

沿用 CC 的整体样式与十三种工具配置服务。服务固定为当前产品的 `https://csmy.fun:23457`，不提供自定义地址、第三方供应商、OAuth 官方供应商或任意配置导入入口。现有自有站公开设置确认注册、邮箱验证和找回密码均开启。找回密码发送重置邮件，邮件链接通过自有网站完成重置，不在桌面保存重置令牌。

采用前后端统一门禁：首次启动先验证存储会话，刷新成功才挂载主界面；注销/会话失效回到登录页；原生 IPC 和转发路径另行限制会话及目标地址。启动不再导入第三方 live 配置或 seed 官方供应商，不删除原有文件。已保存的非自有供应商不展示也不启用。

每个工具提供一个固定 AIHubMix 配置，用户从当前账号 Key 与模型中选择后点击应用，由 Rust 生成配置并调用原 CC provider 服务。通用新增/编辑/导入入口拒绝执行。申请 API 按钮调用现有自有平台 Key 创建接口，保留 Key 分组选择和明确提交；不自动创建 Key 或支付订单。

钱包放在侧栏下部，显示真实币种余额，提供刷新/充值/申请 API/账户入口；会话与用量统计按现状保留。账户页仅管理当前账号 Key 和退出登录。登录页沿用 CC 配色、边框、控件和品牌图标。

验证覆盖：登录前不挂载主应用、失败/过期/退出回到登录、注册验证码/找回邮件、钱包与申请入口、Key/model 切换的异步隔离；原生 URL 精确校验（拒绝伪域名、用户信息、端口变更、非 HTTPS、重定向）、服务限制和配置生成。支付沿用现有回归测试。构建仅本地，不登录真实账号、不发送真实验证码/邮件、不创建真实 Key/订单、不部署发布。
