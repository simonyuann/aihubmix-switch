# CC 卡片与原功能恢复

用户已确认：恢复 CC 官方供应商卡片；按平台模型服务提供固定卡片，卡片只填写 API Key，启动即切换；不提供模型选择器，模型在 agent 中通过 /model 切换。禁止用户新增其他供应商，平台地址仍固定。模型目录由 API 自动读取，原生工具要求目录或默认值时由适配层生成，不另写切换服务。

设置恢复应用配置。MCP、Skills、提示词恢复 CC 原页面及后端操作。会话与用量原逻辑保持；目前空数据已确认为隔离测试 home 无日志，真实 home 有日志。正式验收改用独立产品数据库加真实工具目录的只读扫描，不修改统计/会话实现。

工具页复用 CC ProviderCard，官方卡片使用 CC 官方种子/恢复逻辑，平台卡片由平台服务列表与已有 Key 分组产生；编辑仅允许 Key，不允许地址或模型编辑。启动/恢复调用 CC ProviderService、mode controller。官方恢复授权是用户本轮明确要求的例外，不再受先前“仅自有 API”的一刀切阻止。

余额改为侧栏底部账户入口/紧凑余额区，充值和申请按钮明确分列且不裁切。弹窗在根级挂载，使用 CC Dialog 的 header/body/footer 与滚动区；避免侧栏 transform/white-space 与 overflow 影响。
