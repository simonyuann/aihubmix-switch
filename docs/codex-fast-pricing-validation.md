# Codex Fast 会话用量计价验证

日期：2026-10-27。实现已完成，未打包、未发布，未修改真实用户用量库或平台扣费。

## 行为

- Codex 的 turn_context、thread_settings_applied、token_count 以及 token_usage_record 中的服务档位参与每条请求计价。
- Fast/priority 归一为 Priority；default/standard/显式 null 恢复普通模式。缺失字段保留会话设置，单请求覆盖不改变下一次请求的设置。
- 用已有 pricing_model 记录档位，模型本身、请求 ID、Token、时间和会话身份保持原口径；输入、输出、缓存读取与缓存写入的费用分项均使用档位单价。
- 已核对模型的 Priority 按标准价 2 倍计算；精确自定义档位价格优先。没有对应规则的模型或其他档位维持标准估算并保留档位元数据。
- 在升级后的同步中修正仍保留且能和源日志精确匹配的旧明细。每个逻辑 rollout 的完成状态留在本机 session_log_sync，不重置原游标；事务失败后可以重试，重复执行不会再次翻倍。
- 不恢复已经剪枝的明细，不重算失去逐笔来源的旧汇总；后续汇总直接继承修正后的费用。
