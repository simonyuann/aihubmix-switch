## AIHubMix Switch v0.2.1

修复 Windows / Linux 的 CLI 安装漏检，以及模型不可调用时仍提示导入成功的问题。

- 补齐 OpenCode 官方目录、Scoop、WinGet、pnpm、自定义 npm prefix、nvm、fnm、mise 等常见 CLI 安装路径。
- 打开导入窗口时重新检测，提供「重新扫描」和高级设置中的手动 CLI 路径。显示「未定位 CLI」，不再将检测失败解释为软件未安装。
- 导入前使用本次 Key、所选模型及智能体协议验证真实流式响应与两轮工具调用；验证通过后才备份、写入配置。
- 503、权限错误、限流、流式中断、工具调用失败均会停止导入并保留原配置。HTTP 失败显示模型、接口和服务返回的请求 ID，便于定位后台问题。
- 已接入列表显示「已配置」，并在本机记录导入时的调用验证时间；旧配置不会伪装成已通过新验证。

验证仅使用虚拟连接检查工具，不执行电脑上的工具。每次导入会产生两次简短真实模型请求，可能产生少量费用。它验证导入时的链路，不能保证上游账号池始终可用；平台返回 503 时仍需检查后台渠道、账号与模型的可调度状态。

提供 macOS arm64 / Intel、Windows x64 安装版 / 免安装版，以及 Linux x64 deb / AppImage。macOS 当前为 ad-hoc 签名，尚未 Apple Developer ID 公证；Windows 暂未代码签名。Linux 运行需有可用的 Secret Service，deb 自动安装 WebKitGTK / GTK 系统依赖。

从 v0.2.0 直接覆盖安装即可。已有 API 和配置备份保留；建议对之前失败的连接重新执行一次导入。Claude Code 使用本地兼容连接时保持应用或托盘运行。
