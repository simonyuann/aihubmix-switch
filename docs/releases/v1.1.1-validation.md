## 原 CC Gemini 订阅续期兼容

兼容核查发现此前发行包的 `GEMINI_OAUTH_CLIENT_ID` / `GEMINI_OAUTH_CLIENT_SECRET` 编译参数未提供，会导致 Gemini 官方订阅 access token 过期后无法刷新。现将原 my-cc 使用的客户端参数作为该仓库构建 Secrets 注入；工作流不含参数值，完整打包工作流在缺少配置时直接失败。未修改 OAuth 请求或原 CC 订阅逻辑。

工作流提交 `c81d6e6` 仅修改构建配置；产品标签保持 `v1.1.1` → `67390e0`。最终配置补建任务 `40372105163` 仍检出同一产品标签并行构建三平台，原生回归继续由 `40366822805` 负责；补建不重复运行同一产品源码的完整原生测试，需在公开前核对原任务结果。Apple Silicon 本机也使用相同配置重建，不再使用未注入参数的候选文件。
