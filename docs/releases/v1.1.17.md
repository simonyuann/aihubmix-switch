# AIHub Switch v1.1.17

- 新增 Claude Desktop 中文启动，离线语言资源随应用提供。首次汉化会说明补丁影响并请求系统授权，设置中可恢复同版本原版文件。
- 汉化过程显示实际处理阶段、累计耗时和可计数阶段的完成数量，并提供安全取消。Windows 进一步区分备份检查、旧组件清理、关闭程序、权限准备与文件恢复。
- 修复 Windows 解压版 Codex 的插件管理未使用手动指定路径的问题。插件列表、市场开关、安装和卸载统一使用当前选择的程序及其插件管理组件。
- 设置显示 Codex、Claude Desktop 的实际程序位置。Windows 支持自动检测和手动选择，并明确提示无效路径或缺失组件。
- 延长 Windows 程序识别等待时间，减少繁忙电脑和虚拟机上的误判。
- 修复切换账号后启用当前账号分组时被旧路由归属检查阻止的问题。
- Windows 单文件便携版内置 Claude 中文资源，使用后自动清理临时资源。

Claude 中文补丁会修改应用资源。macOS 会本地重新签名，Windows 新版补丁包含上游的 Claude.exe 完整性信息与 Cowork 签名校验改动，首次操作前会说明并请求确认。Claude 更新后可能需要重新汉化。

macOS 安装包使用本地签名，支持 macOS 12 及以上系统。
