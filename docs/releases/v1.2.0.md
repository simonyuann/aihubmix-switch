# AIHub Switch 1.2.0

- 在 AIHub 的社区插件市场浏览目录，点击安装时才下载并校验所选插件。
- 在“设置 → 关于”安装后续更新时，可查看已下载大小和下载进度。
- 登录、注册使用标准 HTTPS 端口，增加网络诊断并改进慢速连接的处理。
- Codex 聊天模型列表隐藏独立图像模型，保留支持图像工具的聊天模型。
- 首页和工具页支持移除本机模型分组。移除使用中的分组前可选择替代项，切换成功后再移除，云端 API Key 仍可使用。
- 新版通过 HTTPS 443 检查和下载更新。「帮助与答疑」支持复制账号服务及模型接口的诊断结果。

### Windows 发布验收

在隔离 Windows 用户环境安装正式 1.1.18，用专用低额度账号登录并配置 Codex。记录选中的分组、已安装的插件和用户配置，通过独立测试清单安装候选版本。升级后直接使用原登录态和 Key 完成第一条流式回答，核对完整结束标记和一次扣费。再在回答已经输出后模拟连接中断，检查部分回答保留、界面可恢复、上游只收到一次请求。完成全新安装、原地升级、插件安装及更新签名验证后，再切换正式清单。
