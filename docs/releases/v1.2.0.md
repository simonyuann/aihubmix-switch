# AIHub Switch 1.2.0

- 在 AIHub 的社区插件市场浏览目录，点击安装时只下载并校验所选插件。要在 Codex 的社区插件页直接安装，可在 AIHub 的「管理插件」里选择「准备 Codex 插件库」，一次下载后即可使用本机目录。
- 在“设置 → 关于”安装后续更新时，可查看已下载大小和下载进度。
- 登录、注册使用标准 HTTPS 端口。登录时可勾选「记住我」，下次只需点「登录」。取消勾选即可清除本机保存的密码。正常退出后直接返回登录页。
- 修复旧版升级后，Codex 已切换到标准 HTTPS 端口时，登录页可能卡在「无法安全清理旧账号配置」的问题。
- 从 AIHub 启动 Codex 时会提前设置界面语言。汉化结果按界面控件核实，聊天中的英文和原生菜单状态不会干扰判断。
- Codex 聊天模型列表隐藏独立图像模型，保留支持图像工具的聊天模型。
- 首页和工具页支持移除本机模型分组。移除使用中的分组前可选择替代项，切换成功后再移除，云端 API Key 仍可使用。
- 新版通过 HTTPS 443 检查和下载更新。「帮助与答疑」支持复制账号服务及模型接口的诊断结果。

### Windows 发布验收

在隔离 Windows 用户环境安装正式 1.1.18，用专用低额度账号登录并配置 Codex。记录选中的分组、已安装的插件和用户配置，通过独立测试清单安装候选版本。升级后直接使用原登录态和 Key 完成第一条流式回答，核对完整结束标记和一次扣费。再在回答已经输出后模拟连接中断，检查部分回答保留、界面可恢复、上游只收到一次请求。完成全新安装、原地升级、插件安装及更新签名验证后，再切换正式清单。

#### 2026-11-23 候选版本实测

在 Windows 11 ARM64 隔离机上安装正式 x64 版 1.1.18，用临时账号启用 Codex 分组，再把基于 `e1384c3` 构建的 x64 NSIS 候选包安装到同一目录。验收机曾有两个测试安装目录，最后显式指定原目录，并从正在运行的应用读回版本 1.2.0。

| 验收项 | 观察结果 |
| --- | --- |
| 登录与配置 | 应用沿用了账号、当前分组和原 Key。Codex 配置指向 `https://csmy.fun` 的 443 端口，本机技能样本文件的 SHA-256 与升级前相同。 |
| 第一条真实消息 | Windows Codex CLI 0.166.0 收到最终回答 `OK`，产生一次 `turn.completed`。服务端对应一条流式用量，约 ¥0.01891。 |
| 中途断开 | 独立 Windows 测试请求使用升级后的 Codex 配置，收到首段正文后关闭连接。服务端另有一条用量。代理回归测试覆盖保留部分正文、标记未完成和禁止向备用上游重发。 |
| 本机分组移除 | 移除当前分组时必须指定替代项。切换完成后原分组消失，云端 Key 仍可用。重新添加、移除未使用分组均通过。 |

此次使用手动安装的验收包。正式发布前还需验证签名更新链路、Codex 桌面聊天窗口的断线反馈和插件安装。CLI 0.166.0 会提示忽略旧配置项 `disable_response_storage`，本次真实请求仍正常完成。
