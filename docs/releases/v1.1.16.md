# AIHub Switch v1.1.16

- 社区插件库改为通过 AIHub 下载站获取，支持未安装 Git 的电脑。首次开启下载完整资源并显示实时进度，之后可在 Codex 中按需安装和启用插件。
- 平台公告支持 Markdown 标题、列表、链接和图片，修复首次注册时弹窗操作受阻、已读标记恢复以及公告重复弹出的问题。
- OpenAI 分组在 Codex 中显示为 OpenAI，默认模型为 GPT-6.1 Terra，默认推理强度为中。模型列表使用新的排列顺序，并隐藏 gpt-image-2 的对话模型入口。
- 修复读取 Codex 官方模型信息时，分组设置的模型名称和默认推理强度被忽略的问题。
- 精简启动、插件安装、API 管理和余额刷新提示，保留操作结果、进度和必要的重试说明。
- 简洁界面隐藏通用设置中的“侧栏与页头”选项，高级界面继续提供这些设置。

更新后，请在首页重新启用 OpenAI 分组，并重启 Codex，使新的模型设置生效。

插件库首次下载约 375 MiB，下载完成后可重复使用本地资源。macOS 安装包使用本地签名，支持 macOS 12 及以上系统。
