## AIHubMix Switch v0.3.2

已接入的智能体增加连接诊断与快捷操作，首页继续保持简洁。

- 「已接入 → 连接诊断」先检查安装定位、当前配置、Key 状态和本地兼容服务，再由用户主动启动两轮模型与工具验证。会产生少量模型请求费用，打开弹窗不会自动调用模型。
- 诊断按当前已写入的接口格式运行，修改设置中的默认格式不会误测旧连接。发现配置变化、Key 删除或凭据不匹配时，不向模型接口发送请求。
- 报告显示模型、协议、耗时和处理建议，支持复制；隐藏 API Key，不包含原始配置或会话。成功仅代表本次模型工具往返通过。
- 诊断模型请求在后台状态锁外执行，避免等待上游响应时阻塞 Claude 本地兼容连接。
- 「更换配置」直接选择新 Key，并带入当前智能体与保存的模型；无需重新寻找工具。
- 支持会话读取的工具增加「查看会话」快捷入口，自动按来源筛选；保留打开配置目录、复制专用启动命令及条件还原。
- 包含 0.3.1 的 Codex CLI 统一续聊历史、可选旧历史迁移、备份及条件还原，以及系统代理 / 系统根证书支持。

本次回归使用临时配置、SQLite 和本机模拟服务，覆盖诊断只读、当前协议、503 脱敏、配置变化和 Key 删除时不请求模型；未用真实凭据逐一实测第三方工具。服务端或网络入口不可达时，客户端会给出诊断提示，不能替代服务器恢复。

提供 macOS Apple Silicon / Intel、Windows x64、Linux x64 签名更新。已有安装版从「设置 → 检查更新」升级，无需卸载；Windows 免安装版按提示替换。
