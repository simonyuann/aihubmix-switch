- 以原 CC 完整工作区为基础叠加平台功能；设置中增加「启用其他供应商」，默认关闭，开启后恢复 CC 的供应商管理、授权、路由、聚合、导入及高级设置。关闭开关保留已有供应商配置。
- 会话列表直接显示恢复按钮，详情页继续支持在首选终端恢复原会话。

- 设置「关于」不再显示更新日志、最近更新入口及日志摘要，保留版本和检查更新。
- 官方网站改为 https://csmy.fun:23457/。

提供 Windows x64 安装版与便携版，以及 macOS Apple Silicon / Intel；Linux 暂缓。macOS 最低要求 12.0，应用未经过 Apple Developer ID 公证。1.1.x 安装版可使用现有更新通道；Windows 便携版需手动替换。
