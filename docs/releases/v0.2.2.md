## AIHubMix Switch v0.2.2

新增应用内更新：以后发布新版本后，客户端会提示更新，无需卸载。

- 启动后后台检查更新；设置页可手动检查、查看说明和下载进度。
- 下载并通过签名校验后，用户确认「安装并重启」。检查、下载失败不会中断 API 工作台或本地 Claude 兼容连接。
- 更新保留 API Key、登录信息、CLI 路径、智能体配置和备份。安装重启期间，本地 Claude 兼容连接会短暂断开。
- 更新包采用独立密钥签名，并绑定版本；拒绝篡改包、伪造版本和降级。
- Windows 安装版、macOS App、Linux AppImage 与 deb 使用对应更新包。Linux deb 安装时可能需要系统授权。
- Windows 免安装版支持检查版本与打开下载页，下载新的免安装文件覆盖即可；不会静默运行安装版安装器。

### 首次启用

v0.2.1 及更早版本还没有更新入口，需要先覆盖安装 v0.2.2，无需卸载。此后可在客户端内升级。macOS 请将 App 安装到 Applications 后使用更新；Linux AppImage 请放到当前用户有写入权限的位置。

提供 macOS arm64 / Intel、Windows x64 安装版 / 免安装版，以及 Linux x64 deb / AppImage。Release 附 `latest.json`、各更新包 `.sig` 和 `SHA256SUMS.txt`。macOS 目前使用 ad-hoc 签名，未 Apple Developer ID 公证；Windows 暂未代码签名。
