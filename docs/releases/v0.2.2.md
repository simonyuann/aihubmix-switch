## AIHubMix Switch v0.2.2

本次先发布简洁接入助手的稳定修复版，包含应用内更新和 DeepSeek 工具调用修复。更多智能体与 CC Switch 功能扩展将在后续版本提供。

### 应用内更新

- 启动后后台检查更新；「设置 → 软件更新」可手动检查、查看说明和下载进度。
- 下载并通过签名校验后，确认「安装并重启」即可覆盖升级，无需卸载。保留 API Key、登录信息、CLI 路径、智能体配置和备份。
- 更新包绑定版本签名，拒绝篡改、伪造版本和降级。检查或下载失败不影响现有 API 工作台和 Claude 本地兼容连接；安装重启期间连接会短暂断开。
- macOS App、Windows 安装版、Linux AppImage / deb 使用对应更新包；deb 安装可能需要系统授权。
- Windows 免安装版可检查更新并下载对应免安装文件，退出旧程序后替换，不会运行安装版安装器。

### DeepSeek 兼容修复

- 导入验证使用自动工具选择，修复思考模式下强制指定工具导致的 HTTP 400。
- 保留 Responses 明文 reasoning、Chat reasoning_content 及加密 reasoning，支持工具结果返回后的第二轮对话。
- 继续执行两轮真实流式工具验证；验证失败时不修改原配置。

### 跨平台构建

- 修复 Windows 测试进程的 Common Controls v6 依赖，并固定签名测试文件字节，避免 Windows 换行转换破坏验签。
- 提供 macOS arm64 / Intel、Windows x64 安装版 / 免安装版、Linux x64 deb / AppImage。

已有更新入口的客户端可在设置中检查升级；没有更新入口的旧版本请直接覆盖安装，无需卸载。macOS 请将 App 安装到 Applications；Linux AppImage 请放到当前用户有写入权限的位置。

本版不包含新增智能体目录、会话浏览页或 Codex 统一续聊历史开关。Release 附签名更新清单 `latest.json`、更新包 `.sig` 和 `SHA256SUMS.txt`。macOS 使用 ad-hoc 签名，未 Apple Developer ID 公证；Windows 暂未代码签名。
