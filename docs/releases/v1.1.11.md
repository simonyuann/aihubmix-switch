# AIHubMix Switch v1.1.11

- 首页默认显示 Codex 和当前工具的模型分组；可以切换到其他已支持工具。需要更多管理能力时，可在设置中启用高级界面。
- 优化登录、API 管理、充值状态提示、公告和帮助页面；平台公布的联系方式会显示在帮助页。已读公告可在历史记录中查看。
- 更换应用图标，并为页面和操作增加轻量过渡效果；系统开启减少动态效果时会减少动画。
- 改进账号切换时的数据隔离和退出登录的服务端会话撤销；服务端无法确认撤销时会提示用户。
- 支持 DeepSeek Harness 的多个供应商分组；模型在 DeepSeek Harness 中选择。修改配置或切换账号后，请重启正在运行的工具。

macOS 安装包未经过 Apple Developer ID 公证，首次打开时可能需要在系统设置中允许。
