# AIHubMix Switch v1.0.1

修复 Codex 续聊历史统一，并把账户余额直接显示在主页。

- 开启「统一 CLI 会话历史」不再因历史数量或体积被整体拒绝。上限只统计真正需要迁移的会话（其他供应商的历史不再计入），单次可迁移 10 万个会话 / 8 GiB，单个会话上限提升到 64 MiB；仍然逐文件校验、失败整体回滚，迁移前照旧在本地保留会话与索引库的完整副本。
- 会话改写改为逐个文件流式写入，长历史不再依赖内存容量；出错时会话与索引都回滚到迁移前状态。
- 超过上限时会给出具体文件路径和体积，例如「单个会话文件 187.4 MiB 超出上限 64.0 MiB（/路径/rollout-….jsonl）」，不再只有「请先整理历史」。
- 开启后切换官方登录或中转站，`/resume` 始终是同一份列表：官方重新登录会重写 `config.toml`，现在应用启动时按迁移账本自动补回统一分组。
- 已经开启统一历史、但没有迁入旧会话时，新增「迁入既有会话」按钮，无需先关闭再开启；已迁入的会话不会重复处理。
- 主页顶栏直接显示账户余额，点开即进入充值；窗口重新获得焦点、充值完成或关闭充值窗口后自动刷新。未登录时不显示，读取失败时仍可点开查看原因。

Windows、macOS 和 Linux 更新包均由 CSMY 下载站提供签名与校验，已有安装版可直接从「设置 → 检查更新」升级。
