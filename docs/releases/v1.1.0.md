# AIHubMix Switch v1.1.0

基于 my-cc 重构界面与功能后台，配置切换、代理、会话和用量统计复用 CC。

- 首页支持登录、注册和找回密码；登录后进入工具界面，仅支持本平台 API，并保留恢复官方配置。
- 按当前账户已持有的可用 API 添加分组；卡片内选择同组 API Key，点击启动切换配置。模型在 Agent 内通过 `/model` 切换。
- 恢复 MCP、Skills、提示词和设置中的应用配置。右上角显示余额、添加分组及申请 API；左下角提供充值与 API 管理，支持复制和删除确认。
- 使用独立 `.aihubmix-switch` 数据目录；保留原始工具配置、会话和旧备份，切换配置继续由 CC 服务处理。

本次提供 macOS Apple Silicon / Intel、Windows x64 安装版与便携版；Linux 暂缓。下载站在这三种架构、四种更新格式完整校验后自动同步，不等待 Linux。

macOS 最低要求 12.0；应用未经过 Apple Developer ID 公证。首次从 1.0.x 升级请手动下载并安装。重构版使用独立更新通道 `latest-v2.json`（沿用路径名）；旧 `latest.json` 保留已验证的 1.0.x，避免旧 macOS 自动安装不兼容版本。Windows 便携版更新采用下载后手动替换。
