# AIHubMix Switch v2.0.0

整体采用 my-cc 的界面和功能后台，保留 CC 原有供应商、代理、授权、会话、MCP、Skills、提示词、用量和全部 13 种工具入口。

- 在现有侧栏新增 AIHubMix 账户，集中管理登录、Key、钱包和充值。
- 平台 Key 经选择工具和模型后保存到 CC 供应商页；切换和应用继续使用 CC 原有流程。
- 使用独立 `.aihubmix-switch` 数据目录，旧版数据通过明确操作导入并保留原始加密文件和备份。
- 保留 AIHubMix 下载站、更新公钥和安装格式对应的更新通道。
- 最低 macOS 版本调整为 12.0。

旧工具配置和会话不会因导入平台数据而自动改写。旧备份保留单独访问入口。平台账户登录不等于 Codex、Claude 等工具的官方登录。
