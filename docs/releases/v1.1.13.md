# AIHubMix Switch v1.1.13

- 优化自动登录：重启或断网时，可恢复本机加密保存的登录状态；联网后自动验证和刷新会话。余额、充值等在线功能需要网络。
- 修复登录页与后台会话状态不一致时，用户被提示先退出账号而无法登录的问题；切换账号时可在登录页退出本机旧账号。
- 登录信息错误时显示明确提示，方便检查邮箱和密码。
- 修复 Windows 未登录时无法通过托盘右键退出的问题。
- 默认首页只显示平台模型分组，避免误选 OpenAI 官方账号；高级界面和原有官方账号配置保留。
- Windows 不再在任务栏上悬浮余额文字，以避免不同分辨率或缩放下错位；仍可在首页和托盘提示查看余额。
- 插件目录支持继续加载更多结果，并优化 Codex 中文启动的准备流程。
- 基础界面的设置新增 Codex 应用配置，可管理官方登录保留、会话历史、会话压缩和配置目录。
- Windows 启动 Codex 时，会退出当前桌面进程后重新启动；正在运行的任务可能中断，请先保存工作。

macOS 安装包未经过 Apple Developer ID 公证，首次打开时可能需要在系统设置中允许。
