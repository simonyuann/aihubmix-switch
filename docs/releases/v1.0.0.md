# AIHubMix Switch v1.0.0

首个正式版本，完成从 API Key 管理、智能体接入到充值和独立更新的完整流程。

- 导入时只需选择 API Key 和智能体，不再要求在软件内选择模型。后端会从当前 Key 的可用列表中自动挑选与智能体协议匹配的模型，完成真实流式和工具调用验证；导入后可在智能体内使用 `/model` 切换。
- 自动接入 13 种编程智能体，保留原配置和注释，写入前自动备份；验证或多文件写入失败时不留下半成品。
- 支持账号登录、API Key 创建与管理、真实钱包余额、人民币扫码充值、订单查询和取消。
- 支持本机会话浏览、连接诊断、Codex 历史统一、Claude Code 本地兼容连接及原配置还原。
- Windows、macOS 和 Linux 均提供签名更新包。检查更新、下载安装统一通过 CSMY 下载站，用户设备无需访问 GitHub。

本版本继续使用现有更新签名，旧版本可以直接升级。充值到账、模型可用范围和支付限额以服务器返回结果为准。
