## AIHubMix Switch v0.2.0

全新白色界面与 Rust / Tauri 轻量桌面版本，支持 Windows 和 macOS。

- **我的 API**：注册、登录、申请 Key、查看完整 Key 与复制，一处完成。
- **按需导入**：选择 Key 后再选择智能体，只显示当前工具的模型与高级设置；创建后可直接导入，无需手动复制粘贴。
- **已接入**：只展示已配置过的智能体，支持更换配置与还原。Codex、Claude Code、OpenCode、Pi 均支持。
- **Rust 后端**：移除 Electron、Node.js 与捆绑 Chromium，使用系统 WebView；网络请求、密钥存储、配置写入与备份均由 Rust 处理。
- **独立配置**：不同智能体可使用不同 Key，查看或选择 Key 不会改写已有配置。保留 TOML / JSONC 的无关字段和注释，写入前备份。
- **系统凭据保护**：macOS 钥匙串 / Windows 凭据管理器保存主密钥，API Key 和会话凭据加密存储；不回退为明文。
- **充值入口**：已预留，目前显示「即将开放」，暂不支持付款。

### 下载

- Apple Silicon（M1 / M2 / M3 / M4 等）：`macos-arm64.dmg`
- Intel Mac：`macos-x64.dmg`
- Windows 10 / 11 x64：`windows-x64-setup.exe`
- Windows 免安装：`windows-x64-portable.exe`（需要系统已安装 Microsoft Edge WebView2 Runtime）
- macOS 另附 `.app.tar.gz`，所有下载文件附 `SHA256SUMS.txt`。

macOS 安装：打开 DMG，将应用拖入 Applications。最低 macOS 11。当前构建采用 ad-hoc 签名，未使用 Apple Developer ID 签名及公证；首次打开可能被系统拦截，需要在「系统设置 → 隐私与安全性」允许打开。Windows 安装包暂未代码签名。

### 从 Electron 版本升级

首次升级请重新登录，或重新添加已有 API Key。旧版的 `state.json` 与 `backups/` 均保留，原先导入的智能体配置不会自动改写。新版使用 `state-v2.json`、`vault-v2.bin` 与 `backups-v2/`，旧版备份可通过数据目录访问。旧版备份不会自动成为新版的还原记录。

创建 Key、注册和登录需要连接 AIHubMix 服务；充值功能尚未接入后台。不支持网页端两步验证账户直接登录，此类用户可从网页后台取得 Key 后通过「添加已有 Key」使用。
