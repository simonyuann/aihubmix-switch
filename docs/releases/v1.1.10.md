# AIHubMix Switch v1.1.10

- 为本平台的 Codex OpenAI 分组集成原生生图配置，老用户升级后会自动迁移符合条件的当前配置，无需手动复制密钥或修改系统环境变量。
- 更新后请重启 Codex，并在新对话中使用支持图片的模型提出生图请求。实际生图取决于模型、账户权限和余额，费用以平台计费为准。
- 切换到官方账号或其他供应商时，原有官方登录会保留，供应商密钥和生图配置不会沿用到其他供应商。配置曾被手动修改且无法确认归属时，可在软件中重新选择该分组。
- 聚合多个供应商的堆栈模式暂不自动启用此功能，请使用本平台 OpenAI 分组直连或单供应商代理。
- 加强本地代理安全，阻止网页借用代理消耗账户额度；更新配置解析依赖。
- 修复 Codex 经 Chat 格式转发时的会话隔离与缓存问题，以及模型映射下本地用量统计可能重复的问题。账户实际扣费以平台记录为准。
- 修复 Claude 路由使用 GPT 6.1 Sol / Terra 时 Max 思考档位可能被降级的问题。
- 增加 MCP 服务器连接检查，改进本地代理连接提示、IPv6 不可用时的连接速度及 Linux 兼容性。
- 优化启动、后台维护和供应商列表读取，减少界面等待。

macOS 安装包未经过 Apple Developer ID 公证，首次打开时可能需要在系统设置中允许。
