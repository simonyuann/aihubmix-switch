## AIHubMix Switch v0.3.1

Codex CLI 统一续聊历史上线，设置入口保持简洁。

- 「设置 → Codex 续聊历史」默认关闭。开启后，官方登录与本工具导入的第三方连接使用稳定的 csmy 分组；不修改官方 auth.json。当前连接的请求地址保持原用途。
- 既有官方会话仅在用户勾选「同时迁入」后迁移，同步 JSONL 元数据和 SQLite threads 索引，支持归档、CODEX_HOME、sqlite_home / CODEX_SQLITE_HOME。
- 迁移前保存本机备份与操作账本；数据库占用、未知格式、软链接或扫描超限时拒绝迁移。中断操作可在设置中恢复。
- 关闭时可选择按账本还原原分组，保留新增消息、标题和其他字段；用户手动改变分组的记录不会反向覆盖，新建会话不纳入旧迁移还原。
- 修复 Rust 网络依赖未启用系统代理的问题，并读取系统受信任根证书。区分连接超时与等待服务响应超时，保留 TLS 校验，不自动重复登录请求。

请先关闭 Codex CLI 和 App 窗口，再切换或迁移；之后重新启动 CLI。profile、命令行 provider 覆盖及项目级覆盖以 Codex 实际配置为准。其他自定义 provider 需先通过本工具导入，避免覆盖未知认证配置。不同服务之间的加密推理内容可能不兼容。新版 Codex 桌面通常无需此开关。

当前 csmy.fun:23457 的服务入口曾出现 TLS 连接中断；客户端代理修复不能替代服务端连通性恢复。GitHub 签名更新渠道独立于 API 服务。

验证使用临时会话、SQLite 数据库和本机模拟协议服务；未迁移开发机真实历史，未使用真实凭据验证线上登录。提供 macOS Apple Silicon / Intel、Windows x64、Linux x64 安装包，沿用既有更新签名公钥。
