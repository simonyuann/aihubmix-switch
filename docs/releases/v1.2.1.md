# AIHub Switch 1.2.1

- 在首页的 OpenAI 分组上悬停或用键盘聚焦，即可选择当前账号可用的生图模型。下次打开选择器时会刷新列表。
- 插件管理右上角新增关闭按钮。浏览长列表时也能一键关闭，Esc 快捷键仍然可用。
- Linux 用户可在「设置」的 Codex 桌面设置中选择简体中文，再从首页启动已安装的桌面程序。未自动识别时可手动选择程序。若 Codex 已在运行，请先完全退出。
- 侧栏可查看账户余额和充值，帮助与答疑的联系方式中新增 AIHubMix 交流群二维码。
- 改进账号切换、恢复及代理连接处理，优化充值重试和中文版 Codex 的余额不足提示。

### Linux 中文启动兼容性

官方桌面版 `26.1120.50957` 已在 Linux x64 上验证，首次启动和再次启动均显示中文登录页。旧版 `26.1027.51404` 可以启动，登录页仍显示英文，AIHub 会提示「界面语言尚未确认」。
