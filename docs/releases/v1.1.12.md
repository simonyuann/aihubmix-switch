# AIHubMix Switch v1.1.12

- 首页启动 Codex 时，如果桌面程序正在运行，会先请求正常退出，确认退出后再按设置重新启动；如果退出被取消或无法确认，会提示用户手动处理，不会强制结束进程。
- 增加 Codex Desktop 界面语言设置和从首页启动的入口。语言增强的可用性取决于 Codex Desktop 版本和运行平台；Linux 暂不支持增强启动。
- 增加社区插件目录管理，可在 Codex 的本地插件市场中查看和安装公开社区插件。插件来源并非 OpenAI 官方，部分插件或外部服务需要额外授权，安装也需要能够访问对应的代码仓库。
- 改进 Codex 第三方服务商下的命令行生图配置提示和隔离处理；内置生图工具仍由 Codex 和服务端决定是否调用。

macOS 安装包未经过 Apple Developer ID 公证，首次打开时可能需要在系统设置中允许。
