# AIHubMix Switch v1.0.2

修复导入 Codex API Key 后，CLI 启动仍要求选择登录方式的问题。

- 导入时明确使用文件凭据存储，确保 Codex CLI 读取已写入的 `auth.json`，避免原有 `keyring` 或 `ephemeral` 设置导致凭据未被识别。无需先登录 ChatGPT。
- 更换 Key 保留首次导入前的备份；还原时恢复原来的凭据存储设置。
- 补充全新配置、不同凭据存储设置、更换 Key 和还原的回归测试。

已有用户更新后请重新导入一次 Codex，并重新启动 CLI。若仍提示登录，请核对终端与接入助手是否使用相同的 `CODEX_HOME`。

Windows、macOS 和 Linux 安装包与签名更新包由发布流水线并行构建，并在校验完整后公开。
