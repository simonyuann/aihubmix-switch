## AIHubMix Switch v0.3.0

在已发布的 v0.2.2 基础上，借鉴 CC Switch 的工具适配与本地会话管理，保留简洁白色界面。

- 导入目录可搜索，最近使用和已定位 CLI 的工具优先；首页仍只展示 API 与已接入项。
- 自动配置覆盖参考 CC Switch 的 13 种智能体：Claude Code、Claude Desktop、Codex CLI、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes Agent、Pi、MiniMax Code、Kimi Code、Oh My Pi、Antigravity CLI。支持的是各自的配置/启动方式，不代表所有工具都能使用任意协议或模型。
- Gemini CLI 验证原生 Gemini 流式工具往返，再写入 settings.json / .env；保留原 Google 登录配置的备份。自定义 GEMINI_CLI_HOME 按官方目录规则处理。
- Claude Desktop 写入独立的第三方网关 profile，保留已有 profile / MCP。需要支持网关的新版本及 Claude 模型 ID；Linux 取决于桌面移植版本。
- Hermes 添加自定义供应商并设置默认；MiniMax Code / Oh My Pi 添加供应商，模型选择留在原工具中完成。YAML 按托管块编辑，保留其余配置和注释；无法安全编辑的锚点、标签或行内父节点会拒绝写入。MCode 遵守原生配置锁。
- Antigravity CLI 验证 Gemini 接口后生成专用启动环境，需填写与平台模型对应的原生显示名（可从 agy models 查看）。导入后复制启动命令；普通 agy / IDE 官方账号不受影响。专用配置和启动脚本含凭据，按本机敏感文件保护，不要分享。
- Windows 的 Antigravity 命令在 PowerShell 中运行，从私有文件载入本工具生成的命令，不更改系统执行策略，也不将 Key 放进进程参数。原生回归覆盖受限脚本策略、中文和带引号的路径。
- 沿用导入前两轮模型工具验证、备份和条件还原。OpenClaw 支持 JSON5 与自定义配置路径。未定位 CLI 不等于未安装，桌面 App 与 CLI 分别显示。
- 常用编辑器、其他智能体提供独立的手动接入说明和官方入口，明确认证与模型限制。手动说明不等于自动兼容或已通过验证。
- 新增只读会话页，首批读取 Claude Code、Codex、Pi、Grok Build、Gemini CLI、OpenClaw 的文件记录，支持搜索标题、项目与预览，阅读文本，以及复制原工具继续命令。
- 会话不会上传或修改，读取有文件数量、字节与消息上限；工具结果、思考块不展示。Pi 按活动分支阅读，Codex 避免重复显示事件与正文。

Codex CLI 的「统一续聊历史」开关、可选旧历史迁移与还原安排在 **0.3.1**。**0.3.2** 优先完善连接诊断和已接入快捷操作。当前不包含 OpenCode 数据库读取、通用故障切换、统一用量、MCP 或 Skills 管理。跨供应商旧会话能否继续取决于原工具与模型服务，不保证加密推理内容能跨服务解密。

延续 v0.2.2 的 GitHub 签名更新渠道。v0.2.2 安装版用户可在「设置 → 检查更新」升级，无需卸载；Windows 免安装版按对应下载提示替换。macOS 提供 Apple Silicon / Intel，Windows 和 Linux 提供 x64。

验证使用临时配置和模拟协议服务，覆盖配置保留、反复导入、备份还原、Gemini thoughtSignature、工具往返和签名更新。未使用用户真实凭据逐一运行全部第三方智能体，不将模拟结果称为所有版本的线上实测。
