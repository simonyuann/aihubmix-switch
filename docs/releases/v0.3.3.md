# AIHubMix Switch v0.3.3

应用内更新改用 CSMY 下载站。安装此版本后，检查更新、下载更新包及手动下载入口均无需访问 GitHub。

- 更新清单：`https://dl.csmy.fun:23457/updates/aihubmix-switch/latest.json`。
- macOS、Windows 安装版 / 免安装版、Linux AppImage / deb 均从下载站获取对应文件；保留签名、版本绑定和禁止降级校验。
- 下载站完整同步并校验正式 Release 后才原子切换更新清单；同步失败继续提供已有版本。公开目录展示最新版本，旧更新包保留 7 天，供已检查更新的用户完成下载。
- 无法连接下载站时显示中文提示，并提供下载站手动下载入口。

0.3.2 及更早版本的更新地址仍指向 GitHub。无法访问 GitHub 的用户请从下载站手动下载 0.3.3 覆盖安装一次，无需卸载；API Key、登录信息、配置和备份保留。以后升级无需用户连接 GitHub。

新版本仍由 GitHub Actions 构建和发布，服务器每 15 分钟同步。GitHub 暂时不可达只会延迟服务器获取尚未同步的新版本，不影响下载站提供已同步版本。
