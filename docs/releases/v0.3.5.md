# AIHubMix Switch v0.3.5

开放软件内的账户充值。

- 登录后读取真实钱包余额和最近充值记录，提供当前已启用的人民币微信 / 支付宝扫码通道；当前站点提供微信支付。
- 自选金额后主动生成付款码，显示服务端订单的实付、到账和赠送金额，支持本地二维码、打开支付页、主动查询付款结果和取消待付款订单。
- 自动查询当前订单状态，服务端确认完成后刷新余额。关闭窗口停止轮询，重新打开可继续查看本次会话的订单；重启后可查询或取消最近的待付款订单。
- 金额按分校验，通道与限额以下单时服务端配置为准。避免重复提交、已有待付款订单再次创建，以及网络异常时自动重试下单。
- 登录凭据保留在 Rust 后端。支付网络请求在本地 Claude 兼容服务的状态锁外执行。

通过 CSMY 下载站提供签名更新。充值入账仅以服务器确认的订单结果为准。
